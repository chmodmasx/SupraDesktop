# SupraDesktop

Entorno de escritorio independiente para Linux, con macOS 27 como referencia visual y funcional, AI Ready, modular, Rust First y Wayland nativo.

**Estado:** M00 — investigación y especificación. No existe todavía una sesión de escritorio utilizable.

El objetivo es una implementación independiente; no contiene recursos propietarios de Apple ni implica afiliación con Apple.

La documentación fundacional y la arquitectura se mantienen en este repositorio. No se publicarán versiones estables sin superar sus criterios de aceptación.
