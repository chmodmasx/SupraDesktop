# ADR-0012 — Núcleo de ejecución y adaptadores
Estado PROPOSED. Smithay + render graph acotado, recursos GPU con presupuesto, event loop calloop, servicios Tokio con colas acotadas, D-Bus/zbus como baseline y data plane específico. No crear IPC rápido propio sin perfil. App registry único, systemd lifecycle, accesibilidad y Unicode tempranos, plugins fuera del compositor, energía/dispositivos mediante APIs Linux, headless para CI y agentes aislados. Observabilidad local sin telemetría obligatoria. [Especificaciones](../specifications/platform/README.md) y [puertas](../testing/PLATFORM_VALIDATION.md). No elegir toolkit/backend/ABI ni introducir código sin experimentos.
