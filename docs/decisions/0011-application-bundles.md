# ADR-0011 — Experiencia Applications, bundles opcionales
Estado PROPOSED, no decisión de formato definitiva. Motivación: instalación drag/drop tipo macOS, 1:1 funcional, sin fragmentar Linux. Alternativas: nuevo formato completo, solo Flatpak, integración AppImage/AppDir, vista unificada. Preferir vista Applications con providers, ~/Applications real para portables, AppImage/AppDir y .desktop existentes; Flatpak conserva propiedad, permisos y transacciones; la base Arch se gestiona por imagen. .deb queda fuera de la ruta oficial. SupraBundle .app opcional si metadatos/acciones/restauración demuestran brecha, no ABI macOS ni garantía estética. No ejecutar al copiar, no eliminar archivos de paquetes directamente. No crear repositorios o runtimes propios. [Especificación y pruebas](../specifications/platform/APP-BUNDLES.md). Revisar al completar A00.

La experiencia Applications está aceptada por el mantenedor; el formato .app sigue PROPOSED. Ver [ADR-0013](0013-atomic-arch.md).
