# ADR-0011 — Experiencia Applications, bundles opcionales
Estado PROPOSED, no decisión de formato definitiva. Motivación: instalación drag/drop tipo macOS, 1:1 funcional, sin fragmentar Linux. Alternativas: nuevo formato completo, solo Flatpak, integración AppImage/AppDir, vista unificada. Preferir vista Applications con providers, ~/Applications real para portables, AppImage/AppDir y .desktop existentes; APT/Flatpak conservan propiedad, permisos y transacciones. SupraBundle .app opcional si metadatos/acciones/restauración demuestran brecha, no ABI macOS ni garantía estética. No ejecutar al copiar, no eliminar archivos de paquetes directamente. No crear repositorios o runtimes propios. [Especificación y pruebas](../specifications/platform/APP-BUNDLES.md). Revisar al completar A00.
