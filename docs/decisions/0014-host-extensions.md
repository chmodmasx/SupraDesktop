# ADR-0014 — AUR y extensiones host
Estado: PROPOSED. AUR no oficial, no instalación sobre base activa. Separar build limpio y aislamiento real; Distrobox integrado no es sandbox. Rootless Podman y política restringida para casos compatibles; VMs para software no confiable cuando corresponda. Exportar apps al registro. Módulos kernel no pueden aislarse del host mediante contenedores normales. Preferir precompilar v4l2loopback/NVIDIA por imagen; extensiones privilegiadas solo en nuevo despliegue, exacta ABI/kernel, firma, initramfs si corresponde, pruebas y consentimiento independiente. No desactivar Secure Boot ni cargar código privilegiado arbitrario por solicitud de agente. [AUR](../distribution/APPLICATIONS_AUR.md) y [módulos](../distribution/KERNEL_EXTENSIONS.md).
