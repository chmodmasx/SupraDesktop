# ADR-0010 — Infraestructura compartida y adaptadores
Estado: PROPOSED. S01–S15 definen responsabilidades, no microservicios obligatorios. Compartir layout snapshot, geometría, tokens, preferencias, modelo de acciones y autoridades de estado; adaptar estándares XDG/Wayland y toolkits sin duplicar lógica. Taffy/resvg/DTCG/LocalSend y otros candidatos sujetos a pruebas y licencias. QPA versionado por ABI, GTK4/libadwaita no forzar globalmente; extensiones aisladas fuera del compositor. Véase [especificaciones](../specifications/subsystems/README.md) y [puertas](../testing/SUBSYSTEM_VALIDATION.md). Consecuencia: requiere contratos y generación verificable antes de expandir shell. No crear crates vacíos ni afirmar compatibilidad universal.
