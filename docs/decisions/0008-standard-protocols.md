# ADR-0008 — Protocolos estándar primero
Estado: PROPOSED. Usar ext-background-effect-v1 para peticiones de blur estándar si integración verificada; mantener compatibilidad KDE opcional. SupraGlass reserva contratos específicos para parámetros semánticos/ópticos no cubiertos, sin entregar contenido de otras ventanas al cliente. ext-foreign-toplevel-list para enumeración autorizada; acciones de gestión mediante autoridad del compositor. Ventajas: interoperabilidad, menos deuda; riesgos: versiones staging, soporte parcial, diferencias entre implementaciones. Probar negociación y fallback.
