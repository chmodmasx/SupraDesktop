# S01 — SupraIcon: iconos multicapa y materiales
Estado: PROPOSED / NOT_RUN. Referencias públicas: [Icon Composer](https://developer.apple.com/icon-composer/), [WWDC26](https://developer.apple.com/wwdc26/guides/design/), [Icon Theme](https://specifications.freedesktop.org/icon-theme/latest/), [Icon Naming](https://specifications.freedesktop.org/icon-naming/), [resvg](https://github.com/linebender/resvg), [WhiteSur](https://github.com/vinceliuice/WhiteSur-icon-theme). No utilizar recursos Apple.
## Hallazgo
Icon Composer describe capas/grupos con propiedades ópticas por capa, iluminación y variantes. Un SVG plano no necesariamente codifica la profundidad o respuesta dinámica; no inferir parámetros Apple. Freedesktop proporciona resolución de iconos PNG/XPM/SVG, tamaños, escala, herencia y fallback hicolor.
## Diseño
IconResolver (tema, nombre, tamaño, escala), IconScene (capas, grupos, orden, geometría, máscaras), IconMaterial (mate, metal, cristal; roughness, tint, opacidad, altura, normal, reflejo), IconLighting (dirección, luz ambiente, especular), IconRasterizer (resvg candidato para SVG plano; renderer propio para óptica), IconVariants (normal, claro, oscuro, tintado, contraste), IconCache. WhiteSur auditado como proveedor inicial independiente; conservar nombres y créditos. No aplicar squircle obligatorio a cada icono de terceros; distinguir apps, carpetas, documentos, status/symbolic y controles. Atlas GPU opcional y limitado; claves incluyen hash de fuente, versión de receta, tamaño físico, escala, perfil de color, apariencia, iluminación y backend.
Pipeline: raster/vector original -> máscaras y campo de altura -> normales -> iluminación/reflejos -> refracción entre capas cuando corresponda -> composición premultiplicada -> salida. La refracción de un icono no necesita acceder a ventanas privadas. SVG exportable como aproximación estática cuando sea posible; formato nativo versionado para óptica no expresable. Precalcular por variante, no redibujar todo el Dock cada frame. Validar SVG y limitar dimensiones, filtros y recursos externos. Tool de autoría separado, no dependencia runtime.
