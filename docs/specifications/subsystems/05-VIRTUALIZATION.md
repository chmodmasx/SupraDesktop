# S05 — Virtualización de listas y contenido
Fuentes: [GTK list widget overview](https://docs.gtk.org/gtk4/section-list-widget.html), [GtkListItemFactory](https://docs.gtk.org/gtk4/class.ListItemFactory.html), [GPUI](https://github.com/zed-industries/zed/tree/main/crates/gpui).
## Diseño
Modelo paginado independiente de vista; IDs estables, selección y foco persistentes por ID, no índice. Viewport + overscan adaptativo, reciclar nodos con reset explícito (estado, listeners, semántica, imagen). Altura fija: rango directo; variable: estimaciones y árbol de sumas/Fenwick para prefix sums y lookup de offset O(log n), corrección de anchor al medir. Grid responsive, árboles expandidos, sticky headers, listas filtradas y ordenadas, scroll-to-ID. Carga y miniaturas asíncronas con cancelación/priority, no requests ilimitados. Modelo puede enumerar 1M registros sin crear 1M widgets; memoria del modelo se controla con paginación. Accesibilidad anuncia cantidad/posición cuando backend lo permite; materializar elementos al pedir foco. API agentes paginada con permisos, selección por ID, no exposición de filas ajenas. No inventar soporte AT-SPI de nodos virtuales sin probar.
S05a: 10k/100k/1M filas sintéticas, altura fija/variable, scroll, inserción/borrado, resize. S05b: selección, teclado, foco fuera de viewport, búsqueda, accesibilidad. S05c: medir nodos activos, PSS, p95 frame time y latencia; crecimiento visual O(visible + overscan), objetivos concretos tras baseline. S05d: cancelación de miniaturas, reciclado sin mostrar información de otra fila, cambios de modelo concurrentes.
