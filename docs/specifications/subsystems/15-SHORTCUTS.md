# S15 — SupraShortcuts y automatización
Fuentes: [Apple App Intents](https://developer.apple.com/documentation/appintents), [App Shortcuts](https://developer.apple.com/design/human-interface-guidelines/app-shortcuts). App Intents expone acciones/datos estructurados reutilizables por varias superficies; no usar framework Apple en Linux.
## Diseño
Una acción de dominio registrada en SupraActions alimenta UI, menú, teclado, Spotlight, CLI, MCP y flujos. Workflow versionado y tipado: entradas/salidas, nodos de acción, variables, condición y bucle acotado, errores, preview, permisos, timeout, cancelación, efectos y revisión. Editor visual SupraUI separado del executor; validar grafo, tipos, referencias y límites antes de ejecutar. No aceptar código arbitrario como default ni ejecutar instrucciones de documentos. Triggers explícitos manual, evento local permitido, horario opt-in; cuotas y prevención de reentradas/loops. No autoelevar, revalidar permisos por acción, confirmación independiente para operaciones sensibles; no almacenar secretos. Auditar ejecución con redacción y estado, no prometer transacción atómica entre servicios; compensación/undo únicamente donde soportado. Import/export de flujos propios con revisión previa, no ejecutar al importar; no prometer compatibilidad binaria con Shortcuts.
Ejemplo inocuo: crear workspace de prueba, aplicar tema oscuro, abrir app demo; valores y efectos tipados, detener al error y restaurar tema si reversible. Agente puede proponer flujo, usuario revisa, mismo executor y política. No duplicar supervisor, permisos ni catálogo. Offline completo.
S15a: validar tipos, grafo, variables y migración. S15b: flujo sintético, cancelación, error parcial, undo, reanudación no automática. S15c: permisos, revocación, trigger limitado, import no confiable, auditoría con fixtures. S15d: editor visual, navegación teclado, búsqueda y CLI/MCP equivalentes. Sin motor ejecutable todavía.
