# S08 — SupraThumbnails / SupraPreview
Fuentes: [Freedesktop thumbnail spec](https://specifications.freedesktop.org/thumbnail/latest-single/), [Quick Look UI](https://developer.apple.com/documentation/QuickLookUI), [Quick Look Thumbnailing](https://developer.apple.com/documentation/quicklookthumbnailing), [Tumbler](https://gitlab.xfce.org/xfce/tumbler).
## Diseño
Separar miniatura persistente de preview interactiva. Cache XDG estándar: PNG por hash MD5 de URI según especificación (no como seguridad), metadatos Thumb::URI/MTime, variantes de tamaño, invalidación por cambio incluso mtime menor, fail cache según versión, escritura atómica y permisos. Cache adicional propia si tamaño/codec distinto, cuota y eviction. No almacenar miniaturas de ubicaciones sensibles por defecto; verificar acceso antes de servir cache. Scheduler prioriza visible/selección, deduplica, cancela; backpressure y límites de tamaño. MIME detectado por mecanismo confiable; plugins decodificadores separados de UI y compositor.
Candidatos resvg/image/libvips para imagen, FFmpeg para audio/vídeo, Poppler PDF, LibreOffice conversión documentos aislada; auditar licencias y dependencias. Tumbler y .thumbnailer como compatibilidad; no ejecutar comandos arbitrarios de metadatos. Preview: Space, navegación selección, página/zoom, reproducción local, open-with; estado y geometría medidos. No macros, ejecución de código, navegación remota automática ni salida de datos. Parsers no confiables aislados por proceso con acceso solo al archivo permitido y recursos limitados; fallos devuelven icono genérico. API agentes entrega preview únicamente con permisos del archivo.
S08a: cache compartido y stale, cambio URI/mtime, fallos, cuotas. S08b: fixtures de formatos y tamaños, cancelación, primer preview p95, scroll. S08c: archivo inválido, decoder timeout, proceso cae, no afecta Files, no red. S08d: navegación y visual de Quick Look, teclado/a11y, acceso revocado. Sin corpus nativo ni benchmarks.
