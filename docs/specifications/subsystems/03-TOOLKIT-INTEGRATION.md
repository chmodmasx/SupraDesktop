# S03 — Integración Qt/GTK
Fuentes: [QStyle](https://doc.qt.io/qt-6/qstyle.html), [QProxyStyle](https://doc.qt.io/qt-6/qproxystyle.html), [QPA](https://doc.qt.io/qt-6/qpa.html), [QQuickStyle](https://doc.qt.io/qt-6/qquickstyle.html), [GTK settings](https://docs.gtk.org/gtk4/class.Settings.html), [libadwaita appearance](https://gnome.pages.gitlab.gnome.org/libadwaita/doc/1-latest/styles-and-appearance.html), [Flatpak integration](https://docs.flatpak.org/en/latest/desktop-integration.html), [WhiteSur GTK](https://github.com/vinceliuice/WhiteSur-gtk-theme), [MacTahoe GTK](https://github.com/vinceliuice/MacTahoe-gtk-theme).
## Hallazgo
QStyle controla dibujo, métricas, subcontroles y hit test; QPA no garantiza compatibilidad fuente/binaria entre versiones. Qt Quick Controls necesita estilo propio distinto de Widgets. GTK3/4 CSS y GtkSettings no garantizan sustitución integral de libadwaita. WhiteSur documenta problemas al forzar CSS GTK4 y conmutación de modo; evitar ese mecanismo como default. Flatpak necesita extensión compatible con runtime y portal.
## Plan
Paquetes independientes Qt Widgets style (QProxyStyle o implementación propia), platformtheme QPA fijado por versión ABI, QtQuick style, Wayland decoration; GTK3 CSS, GTK4 integración y evaluación de libadwaita fork/patch opt-in; XSettings para XWayland donde corresponda. Rust First permite C++/QML/CSS requeridos por APIs de toolkit. Generar paletas/métricas desde tokens, no duplicar. Estilos de terceros (WhiteSur/MacTahoe, Breeze, Kvantum) como candidatos a estudiar y adaptar tras licencias. No cambiar globalmente archivos de usuario, LD_PRELOAD ni reemplazar bibliotecas del sistema sin ruta reversible. Forks de toolkit necesitan matriz ABI, runtime Flatpak, parches reproducibles y mantenimiento; no imponerlos a todas las apps.
S03a: galería idéntica Qt5/6 Widgets, Quick Controls, GTK3/4 y libadwaita; medir estados, fuentes, geometría, diálogo, contraste. S03b: preferencia live light/dark/accent, escala fraccional, menús/CSD. S03c: Flatpak, XWayland, Electron, apps con custom paint; documentar diferencias. S03d: update toolkit, rollback, coexistencia Plasma y SupraDesktop. Sin benchmarks; no universal 1:1 en apps externas.
