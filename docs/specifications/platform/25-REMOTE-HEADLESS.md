# P25 — Remoto y headless
Fuentes: [RemoteDesktop portal](https://flatpak.github.io/xdg-desktop-portal/docs/doc-org.freedesktop.portal.RemoteDesktop.html), [ScreenCast](https://flatpak.github.io/xdg-desktop-portal/docs/doc-org.freedesktop.portal.ScreenCast.html), [IronRDP](https://github.com/Devolutions/IronRDP), [FreeRDP](https://github.com/FreeRDP/FreeRDP), [libei](https://gitlab.freedesktop.org/libinput/libei).
## Diseño
Distinguir compartir sesión humana (consentimiento, indicador, scope de pantalla/input, revocación/lock) de sesión virtual nueva (backend headless y outputs virtuales, identidad y lifecycle independientes). Headless compositor útil para CI y agentes sin interferir con teclado del usuario; no basta un workspace virtual ni socket Wayland separado para aislamiento de archivos/procesos. Usar entorno aislado gestionado y políticas SupraTrust; no red ni acceso a sesión humana por defecto. Captura autorizada PipeWire, entrada EIS por portal; no crear API de captura/input global indiscriminada. Protocolo externo candidato RDP IronRDP/FreeRDP, no desarrollar códec/transporte propio; servidor opcional deshabilitado, acceso autenticado y cifrado con configuración explícita, revisión de seguridad previa. No autoexponer a Internet, no eludir login ni lock. Control local independiente para finalizar sesión. Clipboard/audio/file transfer permisos separados.
P25a: headless fixture y render determinista, outputs/resolution; b: compartir superficie autorizada y detener/revocar/lock; c: sesiones separadas, recursos limitados y sin acceso cruzado; d: RDP solo entorno de prueba autorizado, latencia, reconexión, escala, audio opcional; e: caída captura y cancelación sin afectar desktop. NOT_RUN. No afirmar soporte de protocolo universal de inicio headless.
