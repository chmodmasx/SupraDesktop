# P29 — Dispositivos externos
Fuentes: [UDisks2](https://storaged.org/doc/udisks2-api/latest/), [BlueZ Device API](https://github.com/bluez/bluez/blob/master/doc/org.bluez.Device.rst), [BlueZ Adapter API](https://github.com/bluez/bluez/blob/master/doc/org.bluez.Adapter.rst), [NetworkManager D-Bus](https://networkmanager.dev/docs/api/latest/), [PipeWire](https://pipewire.org/), [libinput](https://wayland.freedesktop.org/libinput/doc/latest/), [CUPS](https://openprinting.github.io/cups/).
## Diseño
SupraDevices vista agregada, no propietario duplicado: UDisks2 volúmenes/mount/unmount/eject, BlueZ adapter/device/pairing, PipeWire/WirePlumber audio/video nodes, NetworkManager conexiones, libinput seats, CUPS impresión, DRM outputs. Stable identity según backend, no nombre o ruta /dev como única identidad; reconciliar hotplug y servicios desaparecidos. Acciones de usuario con Polkit o servicio autorizado, no root permanente. No automontar/ejecutar contenido arbitrario al conectar USB; respetar política y preferencias, medios no confiables, permisos. Eject coordina operaciones abiertas, no force por defecto. Bluetooth pairing muestra confirmación y no acepta indiscriminadamente; secretos no se exponen al agente. Cámara/mic use indicators donde backend permita atribución, no afirmar cobertura completa. USB/Thunderbolt seguridad gestionada por OS existente, no debilitar. Dispositivos virtuales y fixtures para pruebas; no controlar firmware, fan o hardware fuera de API autorizada.
P29a: USB mount/unmount/eject, disconnect durante copia; b: Bluetooth pairing/cancel/adapter unavailable; c: headset, monitor y teclado hotplug, outputs y ruta audio; d: impresora y servicio ausente, permisos; e: lock, notificaciones y agente con scope. NOT_RUN.
