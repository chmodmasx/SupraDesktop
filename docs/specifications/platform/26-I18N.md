# P26 — Internacionalización
Fuentes: [Project Fluent](https://projectfluent.org/), [ICU4X](https://github.com/unicode-org/icu4x), [Unicode UAX9](https://www.unicode.org/reports/tr9/), [Desktop Entry localized values](https://specifications.freedesktop.org/desktop-entry/latest-single/).
## Diseño
Fluent candidato para mensajes Rust, plurales y selectores; ICU4X para formatos, collations/segmentación según datos y componentes disponibles. No concatenar fragmentos traducidos ni incrustar nombre de usuario como markup; escape y parámetros tipados. IDs estables compartidos con semántica, nunca usar cadena traducida como action id. Locale BCP47 y fallback explícito es-AR -> es -> en según política; idioma UI, formato regional, keyboard layout y zona horaria independientes. Traducir vista Aplicaciones sin modificar ruta real. Nombres de archivos preservan bytes/representación segura; no normalizar destructivamente. RTL con layout direction, bidi isolation, icons direccionales según significado, no espejar logos. Fechas, unidades, números, plurales, 12/24h, sorting local, shortcuts y elipsis. Pseudo-localización para expansión/clipping, tests de CJK/RTL.
