# Automatizaciones

Flujos locales con acciones tipadas y dependencias declaradas; triggers/eventos scoped, límites de frecuencia y ejecución, cancelación, revisión de efectos y auditoría. Desactivar o eliminar un flujo no altera el escritorio. No almacenar secretos en flujos. Revalidar permisos en cada ejecución; no heredar autorizaciones caducadas, no permitir autoelevación. Operaciones de alto impacto requieren consentimiento independiente. Supervisor muestra tarea, identidad, estado, recursos y último resultado; sesión aislada opcional para pruebas y trabajo gráfico.
