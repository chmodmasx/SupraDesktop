Fuentes verificadas documentalmente 2026-11-24: [Anvil](https://github.com/Smithay/smithay/blob/master/anvil/README.md), [Smithay manifest](https://github.com/Smithay/smithay/blob/master/Cargo.toml), [WLCS](https://github.com/canonical/wlcs), [llvmpipe](https://docs.mesa3d.org/drivers/llvmpipe.html), [GPUI examples](https://github.com/zed-industries/zed/blob/main/crates/gpui/examples/README.md), [WWDC26](https://developer.apple.com/videos/play/wwdc2026/102/).
## Compositor
Smallvil es ejemplo mínimo, Anvil banco de pruebas con winit y otros backends. Workspace upstream incluye wlcs_anvil y test_clients; reutilizar patrones y adaptador según licencia. Manifest master declara Smithay 0.7.0, Rust 1.88 y winit beta; no asumir que master equivale a release crates.io. Fijar commit/lock y features mínimas, comprobar compilación en Arch y otro Linux. P0 ventana anidada, socket propio, cliente sintético, foco, resize, popup, salida y frame; P1 render offscreen, surface effects, damage incremental equivalente a redraw; P2 DRM/KMS en hardware. No reemplazar sesión anfitriona. Software renderer para tests, hardware para rendimiento.
## Liquid Glass: nuevos candidatos
[OverShifted/LiquidGlass](https://github.com/OverShifted/LiquidGlass) OpenGL/SDF, metadata MIT. [rukkiecodes/liquid-glass](https://github.com/rukkiecodes/liquid-glass) SDF, normal, Snell, SVG/Skia; sitio indica MIT pero verificar LICENSE y dependencias. [shayann07/liquidglass](https://github.com/shayann07/liquidglass) múltiples backends y mediciones declaradas sobre iOS, metadata Apache-2.0. No afirmar equivalencia a macOS 27, no importar código ni recursos sin auditoría. Comparar shader legible, blur y normal field, calidad de borde, estabilidad temporal, rendimiento y licencia; adaptar únicamente piezas necesarias. Candidato propio GPU GLSL con CPU Gaussian reference. Comparar modelo físico y estilizado, calibrar mediante patrones propios de rejilla/borde/impulso y fondos complejos; separar alpha, tint, specular y displacement. No asumir IOR físico ni parámetros nativos. P0 fixtures offscreen, P1 composición de capas, P2 presión VRAM y fallback. Captura no debe exponer fondos privados a clientes.
## Toolkit
Iced (MIT metadata), libcosmic (MPL-2.0), GPUI (licencia por crate, repo Zed tiene varias), Slint (múltiples opciones; revisar licencia efectiva). GPUI documenta layer-shell y headless; evidencia de ejemplo no prueba accesibilidad. Evaluar misma ventana, menú/panel, scroll virtual, IME y RTL, layout preciso, material within-window, escala, teclado, AT-SPI/Orca y acción tipada, no solo demo gráfica. Gate crítico a11y, control visual, estabilidad, licencias; medir PSS/frame time/input latency. Si candidatos fallan, adoptar/extraer/adaptar o implementar por piezas según necesidad; no construir toolkit completo anticipadamente. No benchmarks ejecutados.
