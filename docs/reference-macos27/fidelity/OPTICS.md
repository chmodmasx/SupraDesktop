# SupraGlass: óptica y sombras
Fuentes: [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/), [WWDC26 State of the Union](https://developer.apple.com/videos/play/wwdc2026/102/), [Niri Window Effects](https://niri-wm.github.io/niri/Window-Effects.html).
Modelos candidatos: backdrop inferior por orden de escena, footprint de muestreo fuera de máscara; gaussian separable como referencia, Dual Kawase como candidato medido. Campo de altura desde contorno, normal normalize(-dh/dx,-dh/dy,1), desplazamiento UV o modelo Snell simplificado; calibrar por rejilla y no asumir IOR físico. Fresnel Schlick F=F0+(1-F0)*(1-cos(theta))^5 como candidato, borde oscuro y especular en canales separados; dispersión solo si evidencia. Tinte y vibrancy con composición/espacio de color documentado y control continuo de apariencia. Adaptación luminosa con estabilidad temporal, no brillo uniforme.
Sombras: convolución de máscara, offset, perfil alfa, capas si medición lo justifica; exterior/interior/reflejo separados. Evaluar orden de blur/refraction/tint con residuales. Behind-window y within-window distintos. Cache invalidada por daño inferior, z-order, geometría, escala y espacio; no reutilizar textura cuando fondo cambia. Sin exponer framebuffer al cliente.
O01: respuesta de impulso/borde/frecuencia, sigma si modelo válido. O02: alfa/tinte sobre colores, residual. O03: campo de distorsión por rejilla. O04: borde, especular, sombra activa/inactiva. O05: fondos dinámicos y comparación caché vs redraw. O06: tintado continuo, estados, contraste/reduced transparency, scroll edge. No constantes ópticas verificadas.
