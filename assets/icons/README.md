## Recursos de terceros libres
Se permiten temas de iconos libres auditados, además de arte propio. WhiteSur Icon Theme es candidato a base reemplazable; véase [ADR-0007](../../docs/decisions/0007-icon-theme.md). No importar recursos Apple ni marcas ajenas sin autorización. Mantener fuentes, créditos, licencias y modificaciones por separado del núcleo.
